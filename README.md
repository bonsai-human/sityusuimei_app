# 命式ノート

四柱推命の命式と西洋占星術のホロスコープを組み、そのまま AI に渡せるプロンプトを
書き出す、個人用の Web アプリです。

すべての計算がブラウザの中だけで完結します。サーバーもログインもなく、入力した生年月日が
外部に送られることはありません。

## できること

画面の上にある切り替えで、**四柱推命／ホロスコープ／両方**を選べます。生年月日の入力は
共通なので、一度書けば両方が出ます。

### 命式を組む

- **四柱** — 年・月・日・時の天干／地支、十神、蔵干（余気・中気・本気）、十二運星、納音、空亡
- **五行のバランス** — 天干4＋地支4の単純カウントと、地支を蔵干の日数比で割り振った加重カウントを並べて表示
- **日干の強弱** — 身強・身弱の機械的な見立てと、そう判定した根拠（得令／失令、通根／無根、助ける勢力の割合）
- **干支の関係** — 支合・三合・半合・方合・沖・刑・自刑・害・破、天干五合・天干沖を、どの柱どうしかまで明示
- **大運と流年** — 起運年齢（小数第1位まで）、順行／逆行、大運10本と各10年の流年。現在地をハイライト
- **そのほか** — 月令（節入りからの日数で決まる司令の蔵干）、節入り日時、胎元、命宮

入力は、新暦／旧暦／旧暦の閏月、出生時刻は時分・時支・不明の3通りに対応しています。

### ホロスコープを組む

同じ生年月日から、西洋占星術の出生図（ネイタルチャート）も出します。

- **天体** — 太陽から冥王星までの 10 天体、ドラゴンヘッド（平均／真を選択）、リリス（平均遠地点）。
  サイン・度分・ハウス・逆行・1 日あたりの動きまで
- **感受点** — アセンダント、MC、ディセンダント、IC、バーテックス
- **ハウス** — プラシーダス（既定）／ホールサイン／イコール
- **アスペクト** — 合・衝・三分・四分・六分（マイナーアスペクトは任意）。オーブと、
  接近中か分離中かまで
- **全体の傾き** — 四元素（火地風水）と三区分（活動・不動・柔軟）の分布、昼夜、
  アセンダントの支配星の居場所、3 天体以上の集まり、半球の偏り
- **出生図の円** — サイン・ハウス・天体・アスペクトを 1 枚の円に。配色の切り替えにも付いてきます
- **めぐっているもの** — 指定した日の天体が出生図のどこへ掛かっているか（オーブは出生図の中どうしより
  狭く取ります）。二次進行（生後1日を1年に読み替えた図）とソーラーリターンの日時も添えます

こちらも相性や運勢を点数にはしません。成立している角度と、そのずれだけを示します。

### プロンプトを書き出す

命式と出生図を LLM に渡す形に整形します。

- **四柱推命の7つのテンプレート** — 総合鑑定 / 今年の運勢 / 大運の流れ / 仕事・適職 / 恋愛・結婚 / 体質・健康 / 自由記述
- **ホロスコープの6つのテンプレート** — 総合鑑定 / 仕事・適職 / 恋愛・結婚 / 月と内面 / 体質・傾向 / 自由記述
- **両方を併記するテンプレート** — 命式と出生図を並べ、**同じことを指している点と、食い違って見える点を
  分けて**述べるよう頼みます。二つの体系は前提が別なので、片方の言葉でもう片方を言い換えさせません
- **3つの形式** — Markdown（表つきで人も読める）／ JSON（構造化）／ 圧縮（トークン節約）
- **含める項目を選択** — 蔵干・十二運・干支の関係・大運・流年、ハウス・アスペクト・感受点・エレメントなど
- **回答の作法を指定** — 「根拠を明示させる」「断定を避けさせる」など。根拠の求め方は、
  四柱推命なら干支と十神、ホロスコープなら天体とサインとハウス、というように言葉が切り替わります

度数は必ず「牡羊座 12°34′（第3室）」の形で渡します。数字だけを渡すと読み違えられるためです。

できあがったテキストはワンクリックでコピーでき、ChatGPT・Claude・Gemini などにそのまま貼れます。
外部に送られるのは、あなたが貼り付けたときだけです。

### 命式をためる

命式に名前とメモを付けて、このブラウザの中（IndexedDB）に保存できます。

- **探す** — 名前・メモ・生年月日でのキーワード検索（`2003-01-10` でも `20030110` でも引ける）、
  干支での絞り込み（`癸未` で完全一致、`癸` や `未` なら含むものすべて）、性別での絞り込み
- **並べ替え** — 更新順・生年月日順・名前順
- **持ち運ぶ** — JSON で書き出し／読み込み。読み込みでは、名前と生年月日時が同じものは飛ばすので
  二重に増えません

### 二つの命式を並べる

保存した命式から相手を選ぶと、いま見ている命式と上下に並び、**柱どうしの関係が線で結ばれます**。

- 破線が天干どうし、実線が地支どうし。線の色は結びつき（合）と揺さぶり（沖・刑・害・破）で分かれる
- 日柱・月柱に掛かる関係は「読み所」として言葉で添える
- 二人の五行の持ち分を並べ、片方に無いものをもう片方が持っているかを示す
- 関係の部分だけを Markdown で書き出せる（命式そのものは「プロンプト」の画面から）

ホロスコープも見ているときは、**二人の出生図を重ねた二重円**（シナストリー）も並びます。

- 内側が自分、外側が相手。ハウスは自分のもので、中央の線が二人のあいだの角度
- **相手の天体が自分のどの室に落ちるか**を両方向とも出します（角度と並んで読まれるところです）
- 読み所として言葉を添えるのは、太陽・月・アセンダント・金星・火星どうしが噛んだときだけ
- オーブは出生図の中どうしより狭く取ります（見る組み合わせが 14 × 14 と多いためです）

相性を点数では出しません。四柱推命の合・沖は良し悪しではなく作用の向きで、何が良いかは
当人が何を望むかによって変わるためです。ホロスコープの角度も同じで、調和の角度が多いことが
良い関係を意味するわけではありません。事実として何が成立しているかだけを示します。

### 人生ログで答え合わせをする

転職・引越し・体調など、日付のはっきりした出来事を書き留めると、**その時期に巡っていた
大運と流年**、そしてそれが命式のどこに掛かっていたかが並びます。

- 年柱は立春、月柱は節で切り替わるので、暦の年月ではなくその日の干支から引き当てる
  （1月の出来事が前年の流年になる、といったずれを取り違えない）
- 大運ごとにまとめて「この10年はこうだった」と読む見方と、日付順に並べる見方を切り替えられる
- その月の柱・その日の柱も添える
- 起運前の出来事や、算出している大運10本の外に出た日付には、その旨を断る

ホロスコープも見ているときは、**同じ出来事に天体がどう掛かっていたか**が並びます。
数日で通り過ぎる天体（月・太陽・水星・金星・火星）は外し、時期を画する木星から先だけを見ます。
同じ出来事を二つの体系から眺める形になります。

出来事と運の対応をまとめて書き出せます。書き出しは「当ててください」ではなく
「噛み合って見えるところと、そうでないところを読んでください」という依頼の形にしてあります。
命式を当てにいくためではなく、自分の命式の読み方を後から確かめるための機能です。

## 公開する

アセットの参照をすべて相対パスにしてあるので、`dist/` を静的ホスティング（GitHub Pages、
Vercel、Netlify など）に置くだけで動きます。サブディレクトリ配信でも設定を変える必要はありません。

PWA として構成してあるので、スマートフォンのホーム画面に追加すればオフラインでも使えます。

### GitHub Pages

`.github/workflows/deploy.yml` が入っているので、**リポジトリの Settings → Pages で
Source を「GitHub Actions」に切り替える**だけで公開できます。以降は既定ブランチに
push するたびにテストとビルドが走り、通ったものが自動で公開されます。

公開先は `https://<ユーザー名>.github.io/sityusuimei_app/` です。

生年月日を他人に見られたくない場合は、リポジトリを private にしてください
（Pages を使うには GitHub Pro などの有料プランが必要になります）。
なお、公開されるのはアプリ本体だけで、入力した内容はあなたのブラウザから出ません。

## 時刻の扱いについて

流派によって解釈が分かれる部分は、設定で切り替えられるようにし、既定値の根拠も画面に出しています。

### 真太陽時

出生地の経度と標準時子午線の差（1度あたり4分）と、均時差（地球の公転軌道と地軸の傾きによる
日ごとのずれ、年間で±16分ほど）を**別々に**算出し、内訳を表示します。それぞれ個別にオン／オフできます。

### 節入りの判定

節入りは地球上のどこでも同時に起きる天文的な瞬間なので、**出生の瞬間**と比べる必要があります。
そのため年柱・月柱・大運は、出生時刻をいったん共通の時間軸に直したうえで節と比較しています。

一方、日柱と時柱はその土地の太陽の位置で決まるので、真太陽時に直した現地の日付・時刻から求めます。
真太陽時の補正を掛けた時刻で節入りまで判定する実装もありますが、それをするなら節入り側も
同じだけ動かさないと辻褄が合いません。ここでは補正の影響を日柱・時柱に限定しています
（差が出るのは節入り前後 30 分ほどの範囲だけです）。

### ホロスコープとの違い

天体の位置は世界時だけで決まるので、**ホロスコープには真太陽時の補正を掛けません**。
時計の時刻から標準時のオフセットを引くだけです。経度は「その瞬間の空をどの向きから
見上げるか」としてアセンダント側で効くので、時刻にも足すと二重に効いてしまいます。

出生時刻が分からないときは、アセンダント・MC・ハウスを出しません（1 時間で 15 度、
ハウスの半分が入れ替わるため）。そのかわり、天体がその日のうちに動く幅を添えます。
アセンダントとハウスには出生地の緯度も要るので、緯度が未入力なら天体だけを出します。

感受点は時刻と経度に敏感です。他の資料と数値が合わないときのために、使った座標と
「時刻が 1 分ずれると ASC・MC が何度動くか」を画面に出しています。出生地の経度が
0.25 度違うのは、時刻が 1 分違うのと同じだけ効きます（都市の代表点をどこに取るかで
数分ぶん変わります）。

### 23時台の扱い

- **早子時説**（既定）— 23時から翌日の日柱に切り替わる
- **夜子時説** — 23時台は当日の日柱のまま、時支だけ子になる

### 大運の起算

- **分単位で厳密に**（既定）— 4320分＝1年として換算
- **日と時辰で** — 3日＝1年、1時辰＝5日として換算

## 構成

```
src/
  core/          純粋な計算層。React に依存せず、すべてテストで固めてある
    constants.ts   干支・五行・蔵干（日数つき）・十二運・納音の表
    ganzhi.ts      十神・十二運・納音・空亡・五鼠遁・五虎遁・胎元・命宮
    relations.ts   合・沖・刑・害・破の表と、柱どうしの走査
    solarTime.ts   経度補正と均時差
    elements.ts    五行カウントと日干の強弱
    chart.ts       入力 → 命式。時間軸の使い分けはここに集約
    compare.ts     二つの命式のあいだの関係と、読み所のまとめ
    lifelog.ts     ある日に巡っていた大運・流年の引き当て
    prompt.ts      命式 → LLM 用プロンプト
    horoscope/     ホロスコープ。四柱推命側とは独立していて、共有するのは入力だけ
      constants.ts   サイン・天体・アスペクト・ハウスの表
      bodies.ts      天体の黄経・黄緯・日々の動き、交点とリリス
      angles.ts      恒星時 → アセンダント・MC・バーテックス
      houses.ts      ハウスの分割（プラシーダス／ホールサイン／イコール／ソーラー）
      aspects.ts     アスペクトの走査、オーブ、接近／分離
      chart.ts       入力 → 出生図。世界時への直し方はここに集約
      transit.ts     ある日のめぐり・二次進行・ソーラーリターン
      synastry.ts    二つの出生図のあいだの角度と、天体の落ちる室
      prompt.ts      出生図 → LLM 用プロンプト。四柱推命と併記する形もここ
  data/cities.ts   出生地プリセット（経度・緯度・標準時オフセット）
  db/database.ts   保存した命式と人生ログ（IndexedDB / Dexie）
  components/      画面
  store/           入力と設定（localStorage に保存）
```

柱どうしの関係の判定は `pairRelations` に切り出してあり、1 つの命式の中（`findRelations`）でも、
2 つの命式のあいだでも、大運・流年が命式に掛ける関係でも（`findCrossRelations`）同じ判定を使います。

柱どうしの関係と同じように、アスペクトの判定も `pairAspects` の一本にまとめてあります。
出生図の中でも、二人のあいだ（シナストリー）でも、その日の空と出生図のあいだ（トランジット）でも、
同じ判定を使います。違うのはオーブの広さと、どちらを a 側に置くかだけです。

暦と節気の天文計算には [lunar-typescript](https://github.com/6tail/lunar-typescript)（MIT）を使い、
蔵干・十神・十二運・納音・空亡・干支の関係は、日本で一般的な表をもとに自前で算出しています。

天体の位置には [astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT）を使い、
見かけの地心位置からその日の真の黄道座標（トロピカルの黄経）を取っています。ハウスの分割と
感受点は自前です。ホロスコープの画面は遅延読み込みにしてあるので、四柱推命だけを使うときは
天体暦を読み込みません。

## テスト

計算層は市販の万年暦アプリの出力と突き合わせたゴールデンケースで固定してあります。
四柱・十神・蔵干・五行・十二運・納音・空亡・月令・節入り時刻・干支の関係・大運・流年・胎元・命宮まで、
1か所でもずれたらテストが落ちます。

境界のケース（立春の前後、23時台、閏月、時刻不明、真太陽時のオン／オフ）も個別に固めています。

ホロスコープの側は、閉じた式で出した値を同じ式で検算しても意味が無いので、**独立に求まる量**と
突き合わせています。アセンダントは地平座標に直して高度 0・方位が東半分にあること、MC は時角 0、
バーテックスは方位 270 度、プラシーダスのカスプは半弧をちょうど 3 等分していること。天体の側は
春分・夏至・朔の瞬間と、時刻の変換は「正午生まれの太陽の時角＝経度差＋均時差」で確かめています。

```bash
npm test
```

## ことわり

四柱推命もホロスコープも、自己理解と娯楽のためのものです。
医療・法律・投資などの判断には用いないでください。

日干の強弱の判定やハウスの分割方式など、流派によって扱いが分かれる箇所については、
このアプリでの見立てが唯一の正解ではありません。根拠を添えてあるので、必要に応じて読み替えてください。
